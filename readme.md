## Cara Menjalankan Notebook

### Menggunakan Google Colab

1. Buka file notebook yang diinginkan.
2. Upload file `.ipynb` ke Google Colab atau buka langsung dari GitHub.
3. Jalankan setiap cell secara berurutan.

### Menjalankan Secara Lokal

Clone repository:

```bash
git clone https://github.com/RegaKurnia/Data_Science-2026.git
```

Masuk ke folder project:

```bash
cd Data_Science-2026
```

Install library yang diperlukan:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

Jalankan Jupyter Notebook:

```bash
jupyter notebook
```

## Kesimpulan

Selama 13 pertemuan pembelajaran Data Science, saya telah mempelajari alur kerja analisis data yang komprehensif dari tingkat dasar hingga lanjut. Pembelajaran dimulai dari dasar-dasar pemrograman Python, pengolahan dan manipulasi data menggunakan Pandas dan NumPy, pembersihan data (data cleaning), eksplorasi data (EDA), visualisasi data interaktif, hingga analisis statistik deskriptif. Lebih lanjut, materi berkembang ke ranah Machine Learning yang mencakup model supervised learning (seperti Logistic Regression, Decision Tree, dan Random Forest penanganan imbalanced dataset), model unsupervised learning (seperti K-Means, Hierarchical Clustering, dan Apriori Market Basket Analysis), sistem rekomendasi dasar, hingga pengenalan Deep Learning (Artificial Neural Network) dan Natural Language Processing (NLP) menggunakan TF-IDF. Setiap model dipelajari beserta teknik evaluasinya, termasuk penggunaan Confusion Matrix, Accuracy, Precision, Recall, dan F1-Score.

Melalui rangkaian praktikum ini, saya memahami pentingnya setiap tahapan dalam siklus hidup data—mulai dari pra-pemrosesan data agar siap dianalisis, pemilihan algoritma yang tepat sesuai permasalahan bisnis, hingga evaluasi dan interpretasi hasil model. Pengalaman ini memberikan pemahaman yang utuh dan praktis mengenai bagaimana memanfaatkan ekosistem Python untuk merancang solusi berbasis data, baik untuk klasifikasi, klasterisasi, prediksi churn, analitik asosiasi, maupun pemrosesan teks.

Melalui praktikum ini, saya memahami pentingnya kualitas data sebelum dilakukan analisis serta bagaimana memanfaatkan berbagai library Python untuk membantu proses pengolahan dan visualisasi data. Pengalaman ini memberikan pemahaman yang lebih baik mengenai alur kerja Data Science, mulai dari pengumpulan dan persiapan data hingga analisis dan pembuatan model prediksi.
